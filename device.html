术语趣解：为什么供电端叫 Source，受电端叫 Sink（水槽）？

在日常英语中，Sink 最常见的含义是“厨房水槽、洗脸池”，作为动词是“下沉”。很多人第一次接触 USB-PD 协议时会大为不解：手机和电脑怎么成了“水槽”？这其实源于电气工程中最经典的“水流模型（Fluid Metaphor）”：

🚰 电路中的经典“水流模型”

电气工程学把电流比作水流：Source（泉眼 / 水龙头） 是水流涌出的源头，在电路中称为“源（电源/供电端）”； 而 Sink（水槽 / 汇水池） 是承接、吸收和蓄存水流的容器，在电路学中专门称作“汇（受电端/负载）”。

❄️ 类似概念：CPU 的 Heat Sink

电脑 CPU 上的散热片在英文中叫 Heat Sink（散热器 / 热汇），含义是“把热量全部吸收吞没进去”。 手机里的锂电池就是一个吸收电能的“电量蓄水池”，因此被称为 Power Sink。

🔄 双角色设备：DRP (Dual-Role)

充电宝和笔记本就像带水泵的“蓄水库”：插插座给自己充电时是 Sink（接水受电）； 拔下来给手机供电时又瞬间切换成 Source（放水供电）。这在 PD 规范中叫 DRP（双角色电源）。

🕹️ 设备端遵循 PD 协议的核心步骤

从检测到插入、评估充电头广播到发出 Request 请求的完整流程：

1. Rd 下拉阻抗宣告身份

未连接时设备处于受电就绪状态：

  • CC 引脚内置有 5.1kΩ 的 Rd 下拉电阻；
  • 插入线缆后，充头感知到电压被分压拉低，确认有受电设备接入，正式启动 5V VBUS 供电。

2. 解析 Source Cap 报文

设备内部的 PD 控制芯片（TCPM）倾听来自充头的能力广播：

  • 比对充电头的所有 Fixed、PPS 与 AVS 档位；
  • 根据设备当前电池健康、剩余电量与温度，寻找“能量与发热比最高”的最佳档位。

3. 发送 Request 并维持心跳

设备主动指定索要的电压与最大电流：

  • 回复 Request 报文（指定所选的 PDO 序号）；
  • 充头回传 Accept 与 PS_RDY 后，VBUS 才会安全升压；
  • 在 EPR 模式下，设备必须每隔数百毫秒发送 EPR Keep-Alive 保活心跳。

⚠️ 避坑专题：为什么很多高性能百瓦充电头，充不了你的耳机手环或剃须刀？

在数码生活中，很多人会遇到“插百瓦氮化镓充电头，耳机仓毫无反应，但用老旧五福一安（5V/1A）却能充”的怪现象。这主要源于以下两大设计根源：

1. 硬件缺陷：受电端漏焊 5.1kΩ 下拉电阻 (Rd Missing)
很多低成本 TWS 耳机、电子烟、充电手电筒只是把以前的 Micro-USB 接口机械换成了 Type-C 形状，但为了省钱省工，未在母座 CC 引脚上焊接 5.1kΩ 下拉电阻。 导致当使用 C-to-C 双头线接入合规 PD 充电头时，充电头 CC 脚检测不到阻抗，判定为“未插入任何设备”，坚持输出 0V 断电保护！只有换用 A-to-C 线（强制给 5V）才能充进去。
2. 软件机制：小电流切断机制 (No-Load Cutoff)
智能多口充电器和移动电源为了节能与安全，内部设有“空载自动关断”阈值。智能手环或耳机在充电接近饱和时，电流会缩减至 10mA ~ 30mA。 充电头检测到电流过低，误以为设备已经拔掉，随即自动关闭供电端口。建议选择具备“小电流/微电流模式（双击按键开启）”的充电配件。

⚡ 设备机身内部：电是如何被吃进去的？

🔋 传统多级 Buck 降压 (笔记本)

笔记本内部拥有 3S/4S 多节串联电池与高功耗硬件：

  • 外部输入 20V 或 28V 高压；
  • 主板多相 Buck 芯片将高压降为 12V 充入电池，或直接降为 1.0V 供给 CPU/GPU 核心；
  • 转换效率约 92%~95%，发热散入笔记本风道。

⚡ 电荷泵 (Charge Pump) 直充 (手机)

现代手机百瓦快充的核心黑科技：

  • 利用容性电荷泵做 2:1 或 4:1 减半降压（例如输入 10V PPS，直转 5V 并将电流翻倍为 8A）；
  • 转换效率高达 97% ~ 98%，绕过机身内发热巨大的电感降压元件，实现极速冷充。

🎮 旁路供电 (Bypass Charging)

游戏手机与高性能电竞笔记本的专属策略：

  • 插电高负载打游戏时，受电芯片直接将外部电力引流给主板和处理器，完全不给电池充电；
  • 避免了“边玩边充”产生的电池剧烈发热，延长电池寿命并防止降频卡顿。
